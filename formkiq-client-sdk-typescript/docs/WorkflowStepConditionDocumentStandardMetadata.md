# WorkflowStepConditionDocumentStandardMetadata

Identifies the built-in document metadata field to evaluate for a workflow condition criterion.  Values:  - `PATH` - Evaluate the document path - `CONTENT_TYPE` - Evaluate the document content type 

## Enum

* `Path` (value: `'PATH'`)

* `ContentType` (value: `'CONTENT_TYPE'`)
