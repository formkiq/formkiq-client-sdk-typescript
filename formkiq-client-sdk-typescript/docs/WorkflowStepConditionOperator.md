# WorkflowStepConditionOperator

Comparison operator used to evaluate a workflow condition criterion.  Values:  - `EQ` - Equals - `NEQ` - Not equals - `CONTAINS` - Contains substring or matching value - `NOT_CONTAINS` - Does not contain substring or matching value - `STARTS_WITH` - Starts with value - `ENDS_WITH` - Ends with value - `GT` - Greater than - `GTE` - Greater than or equal - `LT` - Less than - `LTE` - Less than or equal - `EXISTS` - Field exists - `NOT_EXISTS` - Field does not exist - `IN` - Matches one of the provided values - `NOT_IN` - Does not match any of the provided values - `IS_EMPTY` - Source value is empty - `IS_NOT_EMPTY` - Source value is not empty
