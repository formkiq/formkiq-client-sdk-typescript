# DocusignEnvironment

Docusign environment. When omitted from an E-Signature request, defaults to docusignEnvironment in the site configuration.

## Enum

* `Production` (value: `'PRODUCTION'`)

* `Development` (value: `'DEVELOPMENT'`)
